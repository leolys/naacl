\section{Introduction}\label{sec:intro}

Large language model agents act by looping through
observation, reasoning, and action in an external
environment; what the agent believes about the
information it reads enters tool calls and operations
directly, making reliable interpretation of external
content a precondition for execution safety.
Prior work shows that indirect prompt injections in web
pages and tool returns steer agents away from the
user's intent \citep{zhan2024injecagent,
evtimov2025wasp, johnson2025manipulating}, that visual
perturbations hijack multi-step web agents
\citep{wu2024dissecting}, and that deceptive interface
design can be probed systematically
\citep{wang2025agentvigil}: an environment intervenes
not only through explicit instructions but through the
way the agent understands information, shaping the
decisions it makes autonomously.

Charts are prominent among such inputs, and correct and
misleading readings can coexist in the same figure:
charts support misleading inferences even when drawn
faithfully
\citep{lisnic2023misleading, nadib2026guardrail}.
A curve moving upward is observed accurately, but
whether it represents growth depends on the axis
mapping in force; a misleading presentation can thus
induce an agent to apply its customary reading rules
unchanged and convert visible evidence into a wrong
conclusion (Figure~\ref{fig:misleading-pair}).

\label{fig:misleading-pair}
\end{figure}

Multimodal models are systematically vulnerable to such
manipulations in chart question answering
\citep{chen2025unmasking, mahbub2025perils,
mahbub2026chart}, and our companion work under review
formalizes the execution-level consequence: biases
induced by misleading charts propagate into subsequent
actions and change task outcomes on executable web
tasks; in our panel, direct selection recovers 26
accuracy points on the same tasks with faithful charts
(Section~\ref{sec:exp:static}).\footnote{Companion
submission under review; the paired benchmark \bench{}
and the execution-level evaluation protocol it
introduces are described where first used in this
paper.}

Against misleading charts, model-level defenses have
improved chart question answering through tabular
answering and re-plotting \citep{tonglet2025protecting},
but the reliability of verification itself remains
open: intrinsic self-correction can damage initially
correct answers \citep{huang2023large,
li2025decomposing}, reflection and search open new
attack surfaces when the evaluator is exposed to the
environment \citep{wu2024dissecting}, and a model may
identify chart properties correctly yet fail to let
them govern downstream inference \citep{mahbub2026chart}.
Two requirements follow: correction must rest on
checkable evidence, and a corrected interpretation must
actually change subsequent judgments---an added review
round can re-adopt an inapplicable reading as easily as
discover an error.

Stateful execution raises the stakes: an understanding
formed from one chart feeds later planning even after
the chart has left the viewport, so a verified mapping
should keep governing later judgments yet stay revisable on new
evidence.
Reflexion-style memory carries verbalized feedback into
later attempts \citep{shinn2023reflexion}, and
agent-memory systems organize experience into
retrievable state \citep{wang2024survey, hu2025agents};
an inductive chart requires something more specific,
the current validity of interpretations: which rules
have evidential support, which have been refuted, and
what new evidence suffices to change an accepted
reading?
We pose one unified question: \emph{how can an agent
reliably revise visual interpretation rules, and keep
validated rules in force over subsequent execution?}

We answer this question with a defense that combines
\emph{competing explanation chains} with a
\emph{persistent rule state}, harness-level
externalization \citep{zhou2026externalization} put to
defensive use.
When the agent forms a chart-dependent judgment, the
harness expresses it as $O\land B\Rightarrow C_q(a)$:
an observation $O$ in the chart, an interpretation rule
$B$ that turns the observation into task meaning, and
the conclusion $C_q(a)$ that an action $a$ requires
under the task $q$.
The harness then builds candidate chains with different
interpretive bases on the same complete chart, turning
default visual conventions into explicit objects of
test, and compares their applicability using evidence
drawn from the figure itself.
Validated rule revisions enter the agent's runtime
harness as an interpretation state that later reasoning
reads and updates by scope; subsequent decisions reuse
the rules currently in force, and re-enter verification
only when new effective evidence challenges them.
Competing explanations determine why an interpretation
needs to change; the persistent state carries that
evidenced change into later actions.

Contributions: (1) a correction framework based on
competing explanation chains, where
$O\land B\Rightarrow C_q(a)$ unifies visual observation,
interpretation rules, and action judgments, and
customary readings are tested against in-chart evidence
so the rules behind wrong inferences are identified and
revised; (2) a stateful defense for continuing
execution, where validated rules, revision evidence,
and scope conditions are maintained as task-scoped
harness state, so later decisions reuse confirmed
readings and revise them only on new effective
evidence.
