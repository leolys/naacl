\section{Introduction}\label{sec:intro}

Large language model agents act by looping through
observation, reasoning, and action in an external
environment; what the agent believes about the
information it reads enters tool calls and operations
directly, making the reliable interpretation of
external content a precondition for execution
safety.
Prior work has shown that indirect prompt injections
buried in web pages and tool returns can steer an agent
away from the user's intent \citep{zhan2024injecagent,
evtimov2025wasp, johnson2025manipulating}, that
perturbations of visual input can hijack multi-step
web agents \citep{wu2024dissecting}, and that deceptive
interface design can be reproduced and probed
systematically \citep{wang2025agentvigil}.
These findings indicate that an environment does not only
intervene on an agent through explicit instructions; it
can also act on the way the agent understands and uses
information, and thereby shape the decisions the agent
makes autonomously.

Charts are a prominent part of such external
information: they organize data into visual forms that
support comparison and inference, and lend an
appearance of evidential support to whatever judgment
is attached to them.
Yet correct and misleading readings can coexist in the
same figure: charts support misleading inferences even
when drawn faithfully \citep{lisnic2023misleading,
nadib2026guardrail}.
A curve moving upward is observed accurately, but
whether it represents growth depends on the axis
mapping currently in force; color intensity and bar
height are likewise read through the present figure's
encoding relations, and a misleading presentation can
induce an agent to apply its customary reading rules
unchanged, converting visible evidence into a wrong
conclusion (Figure~\ref{fig:misleading-pair}).

Multimodal models are systematically vulnerable to such
manipulations in chart question answering
\citep{chen2025unmasking, mahbub2025perils,
mahbub2026chart}, and our companion work under review
formalizes the execution-level consequence: biases
induced by misleading charts propagate into subsequent
actions and change task outcomes on executable web
tasks.\footnote{Companion submission
under review; the paired benchmark \bench{} and the
execution-level evaluation protocol it introduces are
described where first used in this paper.}

Against misleading charts, model-level defenses have
improved chart question answering through tabular
answering and re-plotting procedures
\citep{tonglet2025protecting}, but the reliability of
the verification itself remains open: intrinsic
self-correction can damage initially correct answers
\citep{huang2023large, li2025decomposing}, and when the
evaluating component is itself exposed to the
environment, reflection and search can open new attack
surfaces \citep{wu2024dissecting}.
Chart-domain studies observe a further gap: a model may
correctly identify chart properties during extraction
and still fail to let them govern downstream inference
\citep{mahbub2026chart}.
These observations point to two connected requirements:
correction must rest on evidence that can be checked,
and a corrected interpretation must actually change
subsequent judgments---repeated observation or an
additional review round can as easily re-adopt an
inapplicable reading as discover an error.

Stateful execution raises the stakes beyond chart
question answering: an understanding formed from one
chart feeds later planning even after the chart has
left the viewport, so a verified mapping should keep
governing later judgments yet stay revisable on
sufficient new evidence.
Reflexion-style memory carries verbalized feedback into
later attempts \citep{shinn2023reflexion}, and recent
agent-memory systems organize experience into
retrievable state \citep{wang2024survey, hu2025agents};
an inductive chart requires something more specific,
the current validity of interpretations: which rules
have evidential support, which have been refuted, and
what new evidence suffices to change an accepted
reading?
We pose one unified question: \emph{how can an agent
reliably revise visual interpretation rules, and keep
validated rules in force over subsequent execution?}

We answer this question with a defense that combines
\emph{competing explanation chains} with a
\emph{persistent rule state}.
When the agent forms a chart-dependent judgment, the
harness expresses it as $O\land B\Rightarrow C_q(a)$:
an observation $O$ in the chart, an interpretation rule
$B$ that turns the observation into task meaning, and
the conclusion $C_q(a)$ that an action $a$ requires
under the task $q$.
The harness then builds candidate chains with different
interpretive bases on the same complete chart, turning
default visual conventions into explicit objects of
test, and compares their applicability using evidence
drawn from the figure itself.
Validated rule revisions enter the agent's runtime
harness as an interpretation state that later reasoning
reads and updates by scope; subsequent decisions reuse
the rules currently in force, and re-enter verification
only when new effective evidence challenges them.
Competing explanations determine why an interpretation
needs to change; the persistent state carries that
evidenced change into later actions.

Contributions: (1) a correction framework based on
competing explanation chains, in which the relation
$O\land B\Rightarrow C_q(a)$ unifies visual observation,
interpretation rules, and action judgments, and
customary readings are tested against in-chart evidence
so the rules responsible for wrong inferences are
identified and revised; (2) a stateful defense for
continuing execution, in which validated rules,
revision evidence, and scope conditions are maintained
as task-scoped harness state, so later decisions reuse
confirmed chart readings and revise them only on new
effective evidence.
