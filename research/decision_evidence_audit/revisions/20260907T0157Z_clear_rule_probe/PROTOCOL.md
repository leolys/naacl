# 明确规则开发样本：自然错误与提交前纠正检查

日期：2026-09-07。执行依据：用户本轮授权“用规则明确的几个样本来确认能否产生真正可解释的错误和纠正轨迹”。

## 范围与问题

仅使用预先选定的 pub010、env008、b035。每题 official140（原误导图表）与 clean140（对应清洁图表）各一次自然前缀，随后 B0/B2/B3/B4 共 24 个分支运行单元。它们已用于历史开发，不是假装未见的测试集。仅检查个案，不估计方法总体有效率，不启动完整 pilot、新机制、GUI-Reflection/SRC/ExACT 的重跑。

| 任务 | 公开决策规则 | 原始 spec 家族 |
|---|---|---|
| pub010 | 1880–1891 游客数量整体增加就选择增长规划，减少就选择下降响应 | public39_tasks.jsonl |
| env008 | 找出可再生能源发电贡献最大的来源，将该来源送去优先跟进 | environment35_tasks.jsonl |
| b035 | 2018–2023 产量整体上升就扩产规划，下降就效率审查 | business47_tasks.jsonl |

只替换现有 adapter 的任务文件解析，保持模型提示词、浏览器页面模板、公开选项排序、提交前触发器、四种策略及真实本地 HTTP 提交链路不变。原 stage-two 默认入口仍只允许 env001/env025；新增显式 `--profile clear-rule-probe`。不是原始完整网站端到端测评：安全 shell 保留主决策与提交/确认，未复现原站全部伴随表单字段或业务流程。

## 四种后续策略（报告不只写字母）

- 原样继续（B0）：不做额外模型核查，执行已提出的提交。
- 重看完整图表并核对任务语义（B2）：一次独立看图选择，不给核查调用原选择。
- 通用主动视觉核验（B3）：可以直接决定，或自行选取已观察截图的区域；最多两次裁剪、三次模型调用。不能把它没用裁剪说成用了主动观察。
- 模型自行提取后再决策（B4）：同一模型一次提取图表内容，再一次根据提取文本与公开任务/选项决策；不是 oracle 表格，也不是外部 OCR 真值。

## 自然前缀与解释限制

Agent 从任务页起步，最多 12 次模型调用。首次提出业务提交且尚未执行时才暂停；正确选择、错误选择、两种图表条件均触发。没有 checkpoint、解析失败、预算耗尽、没有提交都保留。不得重抽种子直到出错，不得人为预选错误答案。

同一 checkpoint 四分支重新播放相同动作历史，验证恢复后的可见状态与截图相同，然后真实 POST，记录服务器回执和确认页。原图与清洁图的自然前缀分别生成，不能把两者称为同一 checkpoint。

分别检查：原选择是否符合公开规则；核查是否提供可核对的视觉依据；是否改变选项；修改是否真正执行；提交回执是否正确。不能把理由中说对、改了但没提交、提交正确但理由错误混为一谈。原样已正确不是“纠错成功”；自然前缀未记录解释时，不臆测它因标题或柱高而犯错。清洁/误导差异只是这一个种子下的配对行为观察。

## 信息与预算

原图资产、task spec、历史结果保持原样。在线只能获取公开任务/选项、当前与已见截图、动作历史及自身响应；无 gold、误导机制标签、另一 arm、隐藏数据、评测者证据框。源任务名/条件不写入在线别名。离线评分与展示允许查 dataset gold，但 Codex 不替代被测模型。

真实服务仅已有 Qwen3-VL-8B-Instruct 权重，GPU 0，并发 1；不下载模型、不调用其他 API、不打断其他 GPU 任务。模型设置沿用 temperature=0、top_p=1、seed=12345、max_output_tokens=1024、HTTP 自动重试=0。具体服务健康元数据以真实运行工件为准。

本轮真实模型调用总计最多 160，浏览器 transition 总计最多 800；前缀、失败、核查、工具重观察、恢复、提交及多图服务检查全部记录。最初预留 live grid 为 140 次模型调用、600 次 transition；因保留中断和来源记录缺口的 mock 并重新验证，待执行 live 命令先收紧到 550，再收紧到 **380 次 transition**，仍为最多 140 次模型调用，且启动前核对本轮已消耗总账。CPU/mock 与测试另列真实模型调用为零，并将其浏览器 transition 加入本轮总账，不用 mock 正确率支持研究结论。

通用 CLI 仍允许该 profile 下的子集诊断和其他显式解码参数；validator 的 valid 只代表工程一致性，不自动证明任何运行符合本轮固定三题、seed=12345 的研究协议。本轮矩阵要求按实际 run_start 配置人工/离线核对，不能将其他子集或参数冒充该矩阵，不新增锁死未来开发用途的协议门禁。

## 停止条件

完成这 24 个分支（或记录不能完成的原因）即停止。若没有自然错误，则如实报告没有生成纠错机会；若有错误却无纠正，也不得据此断言任何方法完全无效。工程测试成功不等于研究假设成立。
