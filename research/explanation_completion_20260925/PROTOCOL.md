# 完整解释集合补齐：冻结执行协议

日期：2026-09-25。版本：explanation_set_completion_v1。用户已明确授权三例验证，最多 12 次请求尝试、2 美元估算账本；历史额度不延续。

## 输入

固定 b001、b002、pub013 原图，顺序不变。读取原公开 DOM 投影与原 generation.generated 完整集合，不读取旧 proposal、旧 verifier、另一 arm、隐藏表格或 gold。原链/规则数量为 1/1、2/2、1/1。保存全部原文本、顺序、共享规则及来源；不按答案筛选或同选项去重。

原规则 ID r1/r2 保留不重排，新规则使用 supp_rN；初始缺少 chain_id 时按原位置分配 base_cN。任务/图像作用范围在状态中单独绑定，ID 不是跨任务全局规则。公开文字用 public_task + 精确 JSON Pointer 和原文引用；图像观察用 chart_1 + 位置 + 可见内容。

这是回顾性开发诊断，复用既有真实模型初始集合，不是新的自然 agent 前缀。模型输入为静态整图和公开任务，history=[]、无实际当前选择；绝不伪造动作或执行回执。原始生成过程已花费的历史请求独立归因，不混入本轮调用成本。

## 三阶段

1. questions：面向完整集合检查观察、条件或覆盖缺口；最多三个问题，不强制每类都有，不必找冲突。
2. supplement：最多两条新解释和两条独立细化记录；问题结果允许新解释、已有链细化、已有覆盖或未解决。不同依据可支持同一动作；无需每项都有对立解释或 discriminator。实际问题为零时此阶段不调用模型，确定性空结果显式标记来源。
3. verification：核验完整初始+新增链以及独立细化；每个目标分别输出 O/B/implication 状态、证据和理由。核验不接收反问者评语、question_responses、候选先后优劣标签、旧核验结果。稳定 ID 的必要引用保留，不宣称完全来源盲化。

核验不以选出赢家为必需输出，不执行表单选择/提交。结构校验不等于语义正确；核验者的观察、解释与“已覆盖”判断仍可能错误。无新增并不证明解释已经穷尽。

## 状态文件与限制

rule_state.json 保存规则原文、任务/图像/组件/条件范围、版本、证据与三维核验记录。B 同一范围内获支持→active，被反驳→revoked，未确定→pending，同规则各链 B 判断不一致→disputed。不以 O 错误自动撤销 B，不以 B 有效推断 C 成立或动作可提交。

细化记录保留目标链、目标规则版本、其本身的核验与状态，不覆盖原链、不偷偷激活一个修改后的规则。其 applied_to_original=false。新规则可以建立自身核验状态；本轮未实现跨步修订控制器。

文件重载检查内容一致。read_rules 对任务、具体图表、组件和条件匹配给适用/不适用/未知；条件匹配值来自外部上下文检查，测试 fixture 的 true 不作为真实模型使用证据。本轮不让 actor 读取执行，无持续有效性或网页完成结论。

## 模型、成本与失败

复用已有 APIYI Chat Completions 客户端和预算实现；请求别名 gpt-5.6-terra，底层实际模型未独立确认。temperature=0，整张原图不重绘/裁剪/缩放。新 schema 比旧版多出逐维证据：生成输出上限 4800 tokens，核验上限 6000；这是新协议固定配置，不是与旧版单变量对照。

正常最多 9 次请求；所有失败与重试计入 12 次上限，串行。每次发送前预留 0.25 美元；按历史估算系数输入 2.5 美元/百万 tokens、输出 12 美元/百万 tokens 记账，不验证当前价格、不称为实际账单。用量未知保留预留；估算达到上限则不继续。该估算不保证账单上限。

继承客户端最多两次传输尝试：明确 HTTP 错误响应中的临时失败及连接建立超时可重试；请求处理结果未知不自动重发。格式失败、核验不确定、零新增或结果不合意不重跑。全局鉴权/额度/未知结果错误停止；单例 schema 错误保留原响应后推进固定下一例，不补抽任务。

MODEL_API_KEY 只在进程环境传入，不写源码、配置或日志。请求正文、响应、HTTP/usage/finish_reason 与账本均保存；不保存 Authorization。无新付费服务、GPU、浏览器业务动作或 API 翻译。
