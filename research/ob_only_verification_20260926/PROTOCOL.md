用户本轮授权几个样本测试与对抗 sub agent。ARIS 保持暂停，仅使用已经运行的 Qwen3.8-27B / localhost:8058；不付费、不启停 GPU、不下载权重、不补旧 run。

固定使用 conditional_expansion_20260926/run_live_001 全部 8 单元：pub001 误导/正常图、b002、pub013，两个原反问来源。共 3 基础任务、4 图输入，而非 8 独立任务。旧/新链全部保留，包括错误、重复和原反问零候选单元。只取其已完成的候选集合，不续跑它未完成的核验。旧展开/图表/规则/gold/旧核验不修改。

## 方法边界

新 prompt 独立编写，不串接旧提示。核验只看 O/B：每个 O 条目判断可见支持、反驳或无法确认；B 分别说明视觉解码依据与业务适用性。不输出 inference、整链有效性、采纳状态或候选 C，不要求从 O/B 推 C；没有新增 C 核验器。

机械投影保持 O/B 原文字、列表顺序与公开任务/选项；ID 改为 r1…用于对应。独立 C 字段移除，但 B/O 自带的行动名或结论式文本不清洗，因此不是严格的结论盲审。旧判定、来源标签、另一 arm、gold/机制标签不进入在线文本。

所有 O/B 及全部核验结果进入一次新选择请求，不按 verdict 隐藏候选或多数投票，不沿用原 C。模型依公开任务、同图和 fallible 检查重新选择公共 option，并给简短依据；证据不足允许 null，不强制完成。不做业务提交、页面重放或持久规则；返回 action option 不等于真实执行成功。

缺观察不等于反驳事实；历史 UI 当前不可见需区分。B 不把常识冒充任务明文，不为结论改目标，不规定印字/几何/图例哪一种永远优先。先给证据再给状态，仍须离线审查文字/状态是否一致。保留混入解码或行动的 O/B，不替模型清洗。移除 inference 仅消除该字段，不证明其余语义一致性已经解决。

## 配置与停止

固定顺序 registration 四单元，coverage 四单元；每单元先 O/B 核验，再新选择。正常 8+8=16 请求，硬上限20尝试含失败；并发1，暂态HTTP最多重试一次，未知传输结果立即停止。结构错误无质量重跑，核验接口失败不调用该单元选择。没有普通重读贡献对照，不按结果追加样本或提示。

temperature0.7/top_p0.8/top_k20/seed12345/thinking=false，与前轮一致；核验输出上限3600，选择700。HTTP timeout 从旧120秒改为300秒，在结果前固定，为逐观察输出留空间；不据此声称模型效果提升。单图/图像原字节相同，服务图像处理保持原部署。模型及部署身份存入 preflight。

完整存 system/user/schema/图片/响应/usage/错误及代码输入哈希。先离线测试和审查再真实运行，运行后对所有结果审查，不只展示成功。比较原候选 C 仅离线描述，不能当同条件因果对照或使用隐藏 gold 代答。已知 tokens 与缺失用量区分。

一次固定面板结束后给中文展示、逐例结论及原始工件，停止。不自动补跑、扩140条、生成持久规则或加候选机制。
