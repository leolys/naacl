# 本轮反问提示：其他结论先行

实际模型输入为 `prompts.py` 中英文；此处是离线中文译文，不是另一次模型请求。没有写入 pub001、州名、颜色答案或误导类别。

## 新反问专用部分

搜索这张图像可能支持的其他具体任务结论。目标是扩展可能的结论集合，而不是批评、否定或审问已有 O、B 或 C。已有结论只用于避免重复，不视为正确答案。

重新观察完整图像。从一个有可能成立的、不同的具体任务结论出发，回看是否有可定位的视觉线索能够引出它。不同结论可以涉及选择对象、比较方向、趋势类别、范围或任务行动，不必是已有结论的逻辑否定。它只是搜索假设，不是必须得到的答案；不要任意猜一个替代结论，再为它编造证据。

最多提出两个搜索问题。每个问题明确写出正在探索的具体结论，以及应重新查看的图面位置／线索；询问这种读法能否构成完整的 O—B—C 候选。不要仅仅询问旧链是否错误、缺少什么条件，或哪一种编码必须有权威性。探索一个明示条件的候选，不要求先确立读法优先级；适用性交给之后核验。

如果初始集合已经覆盖你找到的合理替代结论及其依据，或者没有发现更多有图面依据的可能性，返回空问题列表并说明检查范围。不强迫相反答案、新增链或固定问题数量。避免只换词改写原候选。问题是探索目标，不是观察事实、最终结论或裁决。

输出与旧思路反问相同：

```json
{
  "questions": [
    {
      "id": "q1",
      "question": "在由【可定位图面线索】引出的读法下，是否可能得到【具体候选结论】？这种读法能否形成一条 O—B—C 候选？"
    }
  ],
  "summary": "检查范围与剩余限制"
}
```

## 与旧思路反问的差别

旧思路问：初始集合是否遗漏了观察、规则适用条件或覆盖范围？

新思路问：图面是否可能引出当前集合之外的具体结论，再回找构成这个候选的依据？

只有问题的搜索目标不同。两者共享初始链、全页截图、输出schema、最多两问、下游补充器、核验器及actor。共同补充器只返回新链、已有覆盖或未形成，不返回旧v3的refinement；所以旧分支是旧问题目标的接口适配，不是原v3全流程复现。

## 补充器的配合

回应每个实际问题。能形成候选时，记录实际可见的 O，写明 B 的条件桥接和范围，再给具体 C。B 可以采用尚未证实的读法，但不能循环假定目标 C，不能编造 O 或任务规则。即使编码优先级未明确，也可以先表达一个条件性候选。

新增链必须有实质不同的结论或推导依据，不为凑数复制。结论可以与已有链相同；没有新候选时明确记录已有覆盖或无法形成。保留初始链原文。后续核验不决定赢家，不修改原 C；最终业务动作仍由普通actor作出。

## 本轮不声称的内容

新提示并不保证能发现正确答案；产生另一个结论也不等于解释合理。必须区分是否形成新候选、核验理由是否成立、actor是否改选、是否真实提交以及原评分。所有这些都按实际记录报告。
