# 实际代码改动与边界

本轮实现放在新的 `research/ob_grounded_20260927/`，没有改原图、原任务规则、gold、历史响应或原网页runner。既有18个ARIS技能仍暂停。以下文件都属于这次静态诊断，不代表已移植完整Agent系统。

| 文件 | 实际作用 |
|---|---|
| `prepare.py` | 从已有公开任务与候选机械投影输入，保存图像/来源哈希；只保留原O与B.text/conditions，独立C和旧行动建议另放离线目录。数据/manifest已存在时拒绝覆盖。 |
| `prompts_v1.py`、`prompts_v2.py`、`prompts_v3.py` | 三个分别保存的开发版本；没有在全量期间续加提示。最终v3独立记录外观与印字，每类最多8条，再核对原O和B的必要条件。实际英文及中文对照均保留。 |
| `schema.py` | 四种阶段输出结构及完整记录/观察索引校验。允许重新选择返回null；不含inference或整链有效性字段。id大小写、O拆分重编号不匹配会被拒绝，本轮未离线修补失败。 |
| `run.py` | 仅访问授权localhost服务；串行全局文件锁、调用次数与截止保护；保存完整请求、图片字节、原响应、接受输出和失败；确认结果按身份原样复用到140，包括失败。 |
| `launch.py`、`status.py`、`collect.py` | 只启动/查看本轮诊断客户端及导出快照，不启动模型、不占新GPU、不停止其他作业。运行中快照与完整结果分开保存。 |
| `freeze.py` | 在固定开发结果审阅之后，一次性绑定runner/schema/config/manifest/prompt；核对当前源与真实开发源相同，禁止替换已冻结版本。 |
| `audit_runs.py`、`finalize_costs.py` | 离线汇总实际阶段、失败、模型状态及账本成本，复用结果不重复计费。模型状态计数不是核验准确率。 |
| `audit_final_artifacts.py`、`check_snapshot_links.py` | 核对请求投影、源/图/响应身份、逐次用量与账本一一对应，以及早期快照引用到最终工件的哈希；不判语义正确。 |
| `score_choices_offline.py` | 只在推理后将新公开选项与原标签逐字映射，保留所有状态及跨模型历史参照；不执行原scorer、不生成新gold。 |
| `report.py`、`qa_viewer.py`、`package_delivery.py` | 生成内嵌图像的离线HTML、检查展示与打包工件。中文摘要和审查旁注与原始模型输出分别显示；QA绑定实际HTML的SHA256，打包逐字节核对，不能借用旧页面的PASS。 |

## 三次开发改动怎样区分

- v1：增加不见候选的独立读图；核验O与B的视觉/任务条件，最后重新选择。
- v2：强化字面读图和原必要条件保留，增加实际核对读法片段；把读取非空约束同步到生成schema，并修复非对象原响应保存、崩溃恢复用量旁证等工程问题。
- v3：外观事实与印字事实分开、数量有界，B简化为一个适用性状态和受检读法/证据；不再并列两个容易职责混淆的B判定字段。它仍需核对必要视觉解码及任务条件，不是删去这些条件。

这些是成组开发配置的变动，不是单句提示的因果消融。三版在同一固定开发输入上分别运行，失败保留；没有逐样本挑选最佳版本。v1/v2的准确源在各自 `runtime_source/`，不能拿现在的v3 schema冒充它们当时运行的源码。

## 测试到底证明什么

现有26项离线回归覆盖：候选不可见读取、原条件保留、上下文深拷贝、字段/编号/索引覆盖、空选择、补链范围、预算/截止、拒绝外部端点、恢复不重调、未知传输停止、原始错误响应保存、用量旁证、固定面板身份、原标签精确映射及账本异常反例。测试中涉及HTTP的对象均为mock。

展示QA打开本地HTML，不属于被测任务浏览器transition；真实推理及其结构失败另按实际请求统计。测试通过不能证明图读对、B适用判对或最后选择持续保留核验结论。

最终打包时另修复凭据模式把`task-…`词内片段误报为密钥的问题，仅增加前缀边界，真实JSON键和Bearer仍受检。`test_package_delivery.py`新增3个离线测试，与原26项合计29项通过（`offline_regression_delivery.xml`）。这是有限模式的工程回归，不改在线冻结版本或研究结果，不是全面安全认证。

## 本轮没有实现的东西

没有新增观察选择器、裁剪策略、前提账本、长程回滚、持久规则学习或多Agent被测框架。离线对抗审查者只检查实验与结论，不向Qwen实时提供答案。本轮也没有把反问贡献重新变为待证明前提：136条沿用既有解释候选，4条缺链只补一次O/B，没有全量重新跑反问—展开闭环。
