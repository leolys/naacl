# v3 部分结果独立审查：前三个完成单元

本文件只覆盖 `v3_partial01/runs/v3_dev` 快照的 registration/pub001 误导、registration/pub001 正常、registration/b002。快照 summary 仍为 running，不代表整轮终态；之后应另写完整结论，不回改本快照的模型结果。未查看确认组响应，未调用模型/API/SSH/ARIS，未改运行代码。

三单元都有 READ、VERIFY、DECIDE，共 9 个 HTTP 200 响应。按本快照响应复算输入 34,590、输出 7,179、合计 41,769 token。选择分别为 ME、ME、Edge，没有业务提交。这不是三个独立的新测试任务，也不是整轮成本。

## 已观察到的进展

1. b002 的主要几何关系读对了：READ 将 Firefox 约 85 与 Edge 约 78 分别记下，又单独记录其印字 23% 和 87%；没有像 v2 registration 一样误称 Edge 柱更高。这里的“约 85/78”仍已用了刻度，不是完全不读印字的纯页面几何观测。
2. pub001 正常图能在核验 r1/r2 时反驳 MN、AL、AK 等同最深色的原断言，其中 AK 亮红比 ME 浅是明确可见反证，优于 v2 registration 的全部支持。不过 ID 与 ME 被判同最深色的问题仍保留，不能宣称已全部分清色阶。
3. pub001 正常图的四个 B 都区分“图例支持深色更高”与“公开任务未定义 priority 必须最高或最低”。unclear 有具体任务条件缺口，而不是因为存在竞争解释就笼统无法判断。这一局部职责改进应保留，但不能以 unclear 数量增多本身作为改善指标。

## 单一 B 判定尚未守住必要条件

pub001 误导图与正常图的公开优先级目标没有因换图而变得更明确。误导图 r3 的 B 是“深色=低值，且优先最低值”，r4 是“浅色=高值，且优先最高值”。本次两者都判 supported。理由同时承认最低/最高优先只是解释或 plausible，却改为只要求颜色解码条件被支持。

问题不在“存在两个 supported 就一定矛盾”，而在本版协议要求必要解码和任务条件都有依据；当前理由自己承认任务条件未定，仍以容易确认的图例替代整 B 的证据要求。这正是合并单轴前已提示的掩盖风险，不是把两个旧轴删除就自动完成职责统一。

## b002：更好的观察尚未改变来源优先臆测

registration/b002 的 r3.B 正确承认 Firefox 更高，却以“dashboard 场景中印字默认是主要来源，除非明确另说”为由判 refuted。公开任务要求最大 market_share、用 dashboard values 作依据，没有提供这种永久来源顺序。文本标签可能有误/代表其他指标也没有被具体反证；缺少支持不能自动等于 refuted。

reading_checked 还将原 B 的“标签可能错误，或属于其他指标”压成“标签可能错误”，保留了总体几何优先，但没有忠实保留全部条件分支，并继续引用原候选 Firefox 最高的行动相关部分。DECIDE 延用标签优先并选 Edge；选项与评分是否一致不证明这个 B 核验可靠。

READ 也并非整体正确：它给 Safari 约 20、Others 约 14，却把 Safari 称为 second shortest、Others 称为 third shortest。实际在 Chrome 约 12 之后，应先 Others 再 Safari。关键最高对象读对，不能掩盖其他顺序陈述的内在不一致。

## 引用与通道隔离的执行情况

11 个 reading_checked 都不再是原 B 可直接定位的完整摘录片段，而是模型概述；正常 pub001 的该字段甚至已写入当场的 supported/未定义判断。这违反当前“引用原读法与条件、证据另列”的格式意图。概述不必全部错误，但需逐条核对条件是否变弱；不能用它证明引用忠实性。

pub001 误导 READ 的 appearance_facts 还包括标题文本、High/Low/100/0 及颜色对应关系，说明输出两栏没有变成独立的感知过程。本版只能称尝试区分描述通道，不能称完全消除了印字锚定或业务解码混入。

误导图 r1/O5 仍把“静态图与公开文本没给出 dropdown 当前选择”判 refuted，缺少当前状态证据仍被当成反证。没有表单截图不等于旧表单状态为假。

## 不应夸大的文字现象

b002 r1/O3 的 evidence 开头写 Refuted，随后自行重新核对并明确撤回，最终说明 5% 的字面观察成立，status 也是 supported。因此这是冗长、自我修正的解释过程，不应再报道为“最终字段与结论未消解地相反”。可以要求后续展示突出最终判定，但不能篡改原始文本。

## 当前决定

保持 v3 源码与固定面板继续，不热修、不再为这三个结果开第四版。部分结果支持“主要柱高观察及一部分色阶/任务条件核验改善”，同时明确暴露单一 B 忽略任务条件、来源优先臆测和引用不忠实的残余问题。尚不足以说核验可靠，也不能提前把未完成的后五个单元或 140 条效果当作已知。
