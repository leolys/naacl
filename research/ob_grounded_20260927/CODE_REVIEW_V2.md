# v2 执行前独立审查

结论：**没有发现启动固定 8 单元开发测试的阻塞。** 尚未审阅 v2 模型结果，也未查看确认组响应；本文件不批准有效性结论或无限迭代。

## 已核对

`prompts_v2.py` 没有实体名、样本 ID、具体答案或预设某编码永远优先。READ 要求字面、定位观察，区分相邻小区域、印字与几何，不能猜精确色值；这些是跨样本可应用的描述要求。

VERIFY 新增 reading_checked，要求引用原 B 的读法与必要条件、排除候选动作、不修补原规则。原 B 仍完整传入，没有代码删除其条件，也没有恢复 inference/整链有效性字段。DECIDE 仍根据公开选项重新选择、允许 null，没有执行提交。

schema 将既有非空 visible_facts 约束同步成 minItems=1，并新增 reading_checked 文本字段。它只检查结构，不暗中判语义正确。

run.py 的响应归档现在在 body.get 之前，非对象 JSON 仍留下原始 body 并标明确失败；归档 200 的崩溃恢复另写 recovery_metadata，不改原 response 和 event。这两项在 v1 完成后修改，v1 runtime_source 保留原样；后续统计必须能从恢复旁证/原响应补足已知用量，不能漏计。

## 必须保留的限定

1. reading_checked 当前不是逐字引用或必要条件覆盖的代码证明，只是模型生成文本；后续审查需核对它有没有改写、丢条件或只挑最有利片段。发现问题保存原结果，不静默修复、不质量重跑。
2. 即使字段写对了，模型仍可能在 B 判定里评价具体动作；不得仅因新增字段存在就宣布职责修好。
3. READ 非空和精简字面描述不等于获得有效视觉依据；只有标题或重复公共目标也可能通过接口。
4. 同步改变提示、schema 与通用接口归档，未来观察到的变化不能全部归因于某一个提示句或独立读取本身。
5. 固定 8 单元全部保留，包括 v1 两个空读取失败；确认组仍在最终冻结后一次运行，不用它选择 v2/v3。
