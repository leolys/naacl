# v2 的唯一提示修正

主方法仍以 `METHOD_REVISED_ZH.md` 为准。v2 只澄清其“公开引用”的接口表达：`public_task` 的 `content` 必须是所引字段的精确 JSON 标量值，并保留原类型；布尔值/数字/null 不应转成字符串。

不替模型从字段路径自动填证据、不修改事实、不放松校验、不调整视觉判断、不重写旧链/旧结果。规则状态、actor 提示、原图与评分不变。

单独调试轨迹位于 `live_v2_schema_debug/`。它通过了此前阻断点，并实际执行一次复核和 v1→v2 规则版本更新；终态为证据未解决、未提交。这是类型契约修复证据，不是恢复成功或方法收益证据。
