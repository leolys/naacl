# 140个任务的解释链人工阅览库

## 从哪里看

优先打开本目录最终生成的 `OBC140_REVIEW.html`。它是单文件离线阅览页：原图、任务、结果和界面都内嵌，拷贝到其他电脑后可以直接用浏览器打开，不需要本项目、Python、网络或API密钥。

任务总数不等于生成完成数。请先看页面顶部的“生成／核验／翻译步骤已完成”数量，以及阻塞提示；没有模型结果的位置会明确显示“尚无生成解释链”或“尚未翻译”。

1. 左侧按编号、领域、阶段状态搜索和筛选；也可用上下方向键切换。
2. 阅读公开任务与选项，点击原图放大。图像保持原始字节，没有重新绘图或替换。
3. O 是直接看见的图形属性、相对位置和字面标注；B 是把这些观察解释成任务含义的条件规则；C 是推导出的结论及对应选项。若模型把解读混入 O，原文仍保留供你指出，不会在翻译时替它纠错。
4. 多条竞争解释可能支持同一行动，不要求强行生成相反答案。“生成原始链”与“规范化链”分别显示；规则按准确编号关联，不由展示代码补写。
5. 展开“逐链核验”和“规则状态”看模型判断。核验步骤完成不代表核验结论正确，也不代表已经执行或提交。
6. 可以切换中英对照、中文优先、英文原文。中文只是额外阅读层，不能代替英文事实来源；缺失译文时保留英文并提示缺失。
7. 在任务底部写人工笔记。笔记不改变模型输出或数据标签；建议用顶部“导出审阅笔记”保存JSON，再到别的电脑导入。标为“已人工读完”只表示你读过，不自动成为正确性标注。

## 这批是什么、不是什​​么

- 140个原任务：商业47、公共事务39、环境35、健康19；仅原图条件，不是280条双条件实验。
- 四阶段：未执行的普通选择提案 → O/B/C及竞争解释 → 独立核验和规则状态 → 独立中文翻译。
- 复用已调整的通用观察边界提示，不为pub013或其他任务单独调提示。
- 本批为静态图表／任务解释库，没有网页交互、提交、自然before-submit checkpoint或端到端成功率。
- 37个商业任务的55个配套选择字段在原spec中没有公开选项列表；保留公开字段信息，不拿隐藏正确值补全。本批不宣称重建了完整可执行表单。
- 原任务中已有的公开提示原样保留。既有机制分类只显示在离线元数据区，不传给在线模型，不冒充新增人工审核。

## 文件与过程

- `PROTOCOL_20260923.md`：本批固定协议、信息权限和预算。
- `catalog.json`：全部140个任务、原图和公开输入的固定清单。
- `data/task_*/public.json` 与 `chart.*`：唯一允许送入前三阶段的任务／图片来源。
- `data/task_*/offline.json`：离线审阅元数据，包含原记录；禁止作为在线提示输入。
- `config.json`：模型别名、解码、输出上限、最多重试数。
- `run_panel.py` / `panel_core.py`：断点续跑与四阶段逻辑；只从环境变量读取密钥，文件中不存密钥。
- `runs/obc140_v4_20260923/tasks/<编号>/record.json`：每例阶段状态、解释链、核验、规则状态、翻译。
- 每阶段目录：完整请求、逐次原始响应、路由／用量记录、解析／校验记录。原始错误响应可能包含账户信息，不应直接转发老师；单文件阅览页不嵌入这些错误响应。
- `runs/obc140_v4_20260923/review_data.json`：展示的规范数据；HTML是其生成视图。
- `summary.json` / `budget.json` / `runtime.json`：真实阶段计数、请求尝试、源代码与配置身份。
