# APIYI 小样本模型选型与费用估算

**结论：Terra 是值得继续验证的降本候选；当前不修改接口就能完整运行的参照仍是 Sol。Mini 被请求参数兼容问题阻断，不能判断它的视觉能力。140 条批量生成没有启动。**

## 实际测了什么

固定两个既有开发任务，没有根据本轮结果换题：

| 任务 | 公开图面与任务 | 主要检查点 |
| --- | --- | --- |
| b001 | 欧洲手机份额饼图；Apple 45%、Xiaomi 30%、Samsung 15%、Others 10%，扇区几何与打印百分比冲突。公开目标明确要求按真实数值选择预算品牌。 | 打印字样是否留在观察层；几何与标签是否形成不同解释；是否区分条件规则和可执行依据。 |
| pub013 | 美国州风险着色图；比较 DE、IL、KS，图例浅黄端标 High/100、深红端标 Low/0；进入最高风险州的优先跟进流程。 | O 只写颜色、标签、图例位置；颜色到风险的映射放到 B，排名与行动放到 C。 |

每模型各自运行四阶段：普通未执行选择提案 → 原 v4 O/B/C 与可选竞争解释 → 独立阶段核验及规则状态 → 独立中文翻译。没有业务浏览器动作、提交或 GPU 使用。没有把 Sol 输出作为其他模型的金标。

固定模型为 gpt-5.6-sol、gpt-5.6-terra、gpt-5.4-mini。相同原图、公开目标、选项顺序、提示、temperature=0；阶段输出上限依次 700 / 2200 / 2200 / 6500。未指定 reasoning_effort，因此不是等内部推理预算对照。API 为 APIYI 的 Chat Completions；请求和响应模型字段一致的成功调用仅能证明服务回报的路由标识，不能独立验证后端权重身份。

原图、任务、gold、旧结果、原生成与核验提示均未更改。线上输入不含隐藏标签、机制类别、原始表格或另一图表条件。每模型目录有 140 个准备槽位，但只有上述两个任务进入调用范围，不能按目录数计算完成量。

**实际 17 次请求尝试：15 次 HTTP 200、2 次 HTTP 400；无重试。3 个组合四阶段完成，1 个组合核验结构无效，2 个组合没有获得模型内容。** 不是 17 个任务，也不是 6 个独立基础任务。此前连通检查的 1 次 models 查询、1 次短文本调用属于前一阶段，不计入本面板 17 次，原始记录仍在 `../service_checks/apiyi_20260924/`。

### Sol：现有管线直接可用，但仍有解释边界

b001 的主链将四组打印字样作为 O，B 写“若打印百分比是 intended true values”，C 才比较大小并选择 Apple。第二条链采用扇区角度这一不同解释来源，核验按公开任务要求否定该链对 Others 行动的支持。

有一个重要限制：角度规则 B 被认为条件性成立，规则状态仍是 active，但它对本任务行动的 implication 已被否定。**active 不等于可以执行该行动**。本轮没有发生规则驱动的实际提交，不把这一状态问题说成已观察到错误执行。

pub013 的 O 只包含州颜色和图例字样，B 才建立颜色—风险映射，C 才选择 Illinois。没有把图例 100/0 当作具体州的精确数值。本次没有生成竞争链。

### Terra：降本值得考虑，不能把接口失败算成看图错误

b001 的打印值和 Apple 推论没有发现明显图像误读；拒绝发生在核验回答把公开 `user_goal` 引用写入 `evidence`，其 `ref=task_001`。当前校验器只允许图像引用 `chart_1`。这是来源类型与接口契约不匹配，不是虚构一条图中证据。保留 invalid 终态，没有删除引用、改成成功或重跑。

pub013 四阶段完成，O/B/C 分层与中文条件保留均基本合理。两例都只给主链，没有展示 Sol/b001 的几何竞争链覆盖。提示允许“至多”两条替代解释，因此不能为了多链指标强迫它编造对立答案。

### Mini：当前参数路径不兼容，能力未评

两份实际请求都保存 `max_tokens=700`，未发送 `max_completion_tokens`。服务返回 HTTP 400，错误称 `max_completion_tokens` 得到 0、应至少为 1。不能把它改写成“本地发送了 0”，也不能仅凭回执确定错误发生在网关还是上游哪一层。

本轮不临时更改协议重跑；两个失败都保留。Mini 没有产出提案、解释或中文，无法支持“能力不够”或“可以便宜替代”的判断。

### 本轮参考花费

接口重复返回 prompt/input 等用量别名，且部分嵌套字段为 0、另一别名非 0。汇总器保存冲突路径，按唯一非零量计一次；reasoning 已包含在输出总量内，不再相加。15 个有用量请求合计输入 152,481、输出 13,212 token；返回 cache read 为 0。

### 140 条估算与待定预算

只有 Sol 两例均完成，提供其两例平均成本乘 140 的简单外推：**情景① $33.71；情景② $39.16。** 若把 140 条都按本轮较短或较长那一例计算，分别为 $29.21–38.21 和 $34.48–43.83；这是样本长度敏感性，不是置信区间、报价或费用保证。

## 工程验证与交付边界

- 原有数据、公开输入隔离、请求／状态、展示，以及新增固定选型入口：32 项离线测试通过，3 条既有 Flask 弃用警告。
- 用量折叠、字段冲突、未知费用、预算身份对齐与外推门槛：18 项离线测试通过。
- 三个离线 HTML 均经实际 Edge 检查：两任务、原图内嵌、已有链、缺失状态、中英文切换、放大、窄屏；未发起外网请求。这只是阅读界面验收，不是模型任务成功率。
- 首次使用虚拟环境默认 pytest 插件加载的回归命令长时间没有测试输出，被中断；改为首选 Python 并关闭自动插件加载后完成 32 项。没有因此增加 API 调用。
- 独立子 Agent 做了运行前代码审查和逐例语义复核；属于 Codex 同家族审查，不冒充项目所有者人工审核或跨模型盲评。展示未声称新一轮独立 HTML 审稿，只记录导出自测与浏览器验收。
- 原始运行和失败完整保留。脚本、命令、用量账、配置快照、原始请求响应及阅览派生来源见 [工件索引](MANIFEST.md) 和 [复核命令](REPRO_COMMANDS.md)。

OpenAI Docs 技能用于区分官方模态资料与网关定价；experiment-bridge 要求先做单例打通和独立审查；render-html 只将规范报告生成离线视图，未改变研究提示或模型输出。

## 下一步建议：本轮到此停止

若优先保持现有管线直接可用，选择 Sol 并在确认上限后另启 140 批次。若优先降本，先以新版本做 Terra 的通用证据来源契约适配小检查，保留本轮失败；不能未验证就宣称它与 Sol 等价。Mini 需要另记参数兼容检查，当前不进入能力排序。

本轮所有实际产生的提案起初即为图面／公开任务支持的选择，没有测试错误提案的恢复率。三条完整静态解释记录也不能证明防御已在 140 对 benchmark 上有效。没有启动批量、增加任务、GPU 作业或新机制。
