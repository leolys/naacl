# 实验计划：竞争解释核验与持久解释规则

日期：2026-09-23。依据：用户提供的《paper_chapters_1_and_3_feishu.md》；已有数据丢失的旧验证仅是背景，本轮不记作证据。

## 主张与证据边界

| 待检验主张 | 最少需要的证据 | 本轮能否回答 |
|---|---|---|
| 竞争解释能揭示错误解释条件，改善图表驱动的实际决策 | 与同模型普通重读、等预算核验比较；统计错误→正确、正确→错误及真实提交 | 三例只能验证接口与展示行为，不支持总体优越性 |
| 具有证据、范围和修订状态的规则有助于后续继续使用正确解释 | 原生存在新的合格判断机会；与普通完整历史、等信息文本记忆比较 | 原任务多为一次判断后提交，本轮仅检查写入/读取接口；持续性分母无机会则 N/A |

反解释：收益可能仅来自更多调用、再次看图、任务文字提示或重复记忆，而非两项机制。

## 本轮固定执行：三个开发示例

API 结果之前固定 pub013（反向地图图例）、health004（倒置数值轴）、b046（平均参考线）。不因模型表现换题。这些样本已有开发接触，pub013 更已在文稿出现，不能称作未见测试集。

每个任务保留 official140 与 clean140 原图，共六个条件。每个条件独立从同一公开初始页面运行普通 Agent 与完整方法：总计 12 条轨迹。原图、公开任务、选项、gold 不改；只把泄露答案的内部 action ID 换成中性 UI 值，并按选项可见文字排序，两组一致。完整保留原公开文字，即使文字已有读图提示。

新接口 field_complete_shell_v1 复用旧 safe_shell 的公开投影/选择/真实 POST 设计，并补上原 spec 的公开附加字段。旧 safe_shell 只测主选项；新接口不能与旧结果当作相同协议。隐含常量不交给模型，公开只读上下文可以展示；文本字段不填入参考答案。

普通 Agent 收到完整图表、真实页面截图、全部已执行动作及公开回执。条件式完成：如果模型认为当前选项满足任务且必填完成，可以提交；否则可以更改或重看。禁止强制提交。

完整方法在第一次图表选择提议、尚未执行前触发（所有选择同等触发，不读 gold）。生成当前论证与至多两条实质不同解释，共享规则 ID；独立调用核验观察、规则和推导；执行选择建议后由同一个普通 actor 继续，必须由 actor 真正提出 submit 才提交。保存 KEEP/REVISE/UNRESOLVED。若仍不能解决，允许一次额外全图核验，不注入新的隐藏证据。记录规则范围、状态、证据与版本；不能将推荐选项保存为规则。

这是有界方法原型。范围匹配支持图表引用与公开语义条件；同一静态图表的当前编码组件由核验记录描述。未进行语义等价的外部定理证明；模型规范化失误需记录。依赖撤销规则的显式引用会被拦回核验，但未显式报告的潜在依赖不能保证被发现。

三例没有强制错误。若普通 Agent 已正确，完整方法 KEEP 也是有效观测；不得宣称纠正成功。b046 无打印柱值，只允许读刻度估计，不能在线读取隐藏精确值或 CSV。health004 历史草稿标记与已有筛选记录并存，不由 Codex 改为人工通过。

## 完整 140 对后续配置（准备，不自动执行）

1. **主表（必须）**：140 基础任务×两图表条件，普通 Agent、普通全图目标核验、完整方法。同模型、原始图像、公开历史、选项顺序、正常完成条件与执行器相同。报告主选项原评分、实际提交、必填字段完成、失败/未解决、成本，分图表条件及机制层；不能将重新实现的全字段检查冒称官方 scorer。
2. **贡献隔离（必须，后续）**：竞争解释有/无 × 专门规则状态有/无；无状态仍有完整真实历史。竞争解释移除组采用相同调用上限与全图核验，而非减少预算。再加“同样核验结果放普通文本记忆”，区分状态管理与重复提醒。三种基线家族上限：普通执行、局部核验、普通记忆。
3. **稳定性（有资格机会才做）**：统计核验后再次发生、且涉及相关规则的新判断；未出现机会则 N/A。若原库不支持，单列派生后续问题集并经人工审核，绝不混入原 140 成绩。本轮不生成该派生集。
4. **分层与失败审计（必须）**：数据审计后的机制分类与原标签同时保留；按变式谱系聚类估计不确定性，不能将近重复当独立证据。可见证据不足、原标签争议、读取失败、规则判错、推导不足、执行失败分开。保留 env008 evidence_conflict 等标记，不改 gold、不事后删除冲突任务。

## 划分、统计与计算

完整库 140 对首先是公开总体的描述性评测，不自动称为纯 held-out。旧八任务、三例和其他接触任务都必须写入 exposure ledger；未知接触状态不能标未见。若进行调参，按原任务/父图谱系成组划分开发与确认，清洁/误导 arm 不分离。冻结后先单次全量，预算明确后可 3 次重复；temperature=0 也不保证网关确定性。

建议主指标：误导 arm 的原标签主选项成功、干净 arm 的保持、错误→正确/正确→错误转移、实际提交率与 abstention。错误恢复分母是自然初始错误，不能把注入错误或循环中的多次错误当新样本。配对差异与按谱系 bootstrap 区间，样本少时以逐例描述为主。
