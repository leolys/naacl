# 固定历史开发例的静态迁移诊断

2026-09-26。此子协议在迁移例新模型推理之前固定。主协议是同目录 `PROTOCOL.md`；用户授权使用已有 Qwen3.8-27B 服务探索通用方案。不开新 GPU / 模型服务，不使用付费 API、不恢复 ARIS 技能。

## 固定例子和权限

固定 b002、pub013 两个已经用于开发的原例，不根据本轮推理结果换样本，不把它们称为 holdout。资产来源与审核见 `TRANSFER_ASSET_AUDIT.md`。

每例只做**静态全图候选层面的迁移诊断**，没有实际浏览器选择、pending submit 或业务提交。因此不能报告自主发现错误率、自然 before-submit 恢复率或端到端成功率。

公开输入是原非 review 三页 HTML 已归档投影 `public.json`，仅删除合成别名 `task_alias`。保留完整公开任务、原始目标、选项顺序、伴随字段和公开规则，不自行改变动作语义；当前选择为空、真实动作历史为空、pending_proposal=null。旧 Terra 提议、旧 OBC、旧核验、评分、隐藏答案、误导标签、来源路径均不传模型。

新上下文格式：

```text
goal = public.user_goal
state = {view_mode: static_fullchart_public_task,
         task: 去 task_alias 后的其余完整 public,
         current_selection: ""}
history = []
options = public.option_labels（原顺序）
pending_proposal = null
```

## 图像和传输编码

两例原始 JPEG 均为 3420×2700。模型客户端固定声明 image/png，因此离线准备将 JPEG 解码为 RGB，再以无损 PNG 编码；不裁剪、不缩放、不注释、不重绘。

每例保存原始 JPEG 字节副本、原始 SHA、PNG SHA、两种文件解码后的 RGB SHA、尺寸及像素相等检查。**编码变更不等于图表内容编辑**；相等断言失败就停止。输入 manifest 和路径只用于离线追踪，不进入模型上下文。

既有模型服务 `max_pixels=1605632` 会执行其自身图像预处理，原全图像素数是9,234,000。本地没有放大、裁剪或提供高分辨率附加图。报告记录服务配置，不能把与旧 Terra 的结果差异只归因于提示修改。

## 共享初始生成与两个固定方案

每例用本轮 Qwen、新统一初始生成提示与新公共输入重新生成**一次共享 initial**，不用旧 Terra 链作为 Qwen 的起点。然后同一 initial 分配到以下两种固定策略：

- V1，行动结论列表反问：只把共享 initial 中去重的精确公开 option_label 给反问阶段，不给原 O/B、解释正文、原 claim、ID、重复计数或 notes；其余公共任务和同一图保持一致。随后共同补充器接收真实问题和共享 initial，再进行独立核验。
- V4，逐公开行动分解的假设生成：对**全部公开选项**按原顺序各调用相同通用提示，将该选项作为待考察的搜索假设，最多生成一条 OBC，也可以为空；不读共享 initial。不能跳过已被初始链覆盖的选项，也不能挑“应该正确”的选项。确定性重命名候选 ID 后与共享 initial 合并，用共同核验器核验。

两方案使用主协议冻结的生成 / 核验提示、接口和参数。V4 是程序模板逐行动提出搜索假设，不称模型主动提出了相同问题；额外调用与生成接口差异属于方案整体，不能归因于单一措辞。

迁移initial最多3链，加逐假设最多3链，核验schema的checks容量在执行前明确扩到6；其余字段、枚举及核验system不变，要求准确覆盖全部链ID，不删链迁就原pub001的5链上限。

初始生成可能已经有多条竞争解释，这时“没有新增”不是失败；报告分别保留初始覆盖、新候选、是否真正不同的结论、局部可见依据和核验意见。允许新候选后来被驳回，但不能编造 O 或把目标 C 当 B。不能为了得到多链或正确结论反复质量重跑。

## 预算和停止

迁移运行**继承本轮 pub001 run ledger 的实际累计成本和上限**：合计最多100次真实请求尝试、300次实验浏览器操作，并发1，不因换目录或脚本重置余额。失败、暂态重试和模型请求均计入。当前迁移协议不新增浏览器操作。

两例各最多：初始1；V1提问1、必要补充最多1、核验1；V4三个公开行动各1、核验1；正常请求总上限为16（少于三选项时相应减少，零问可跳过补充）。沿用既有暂态重试边界，不增加质量重试。若账本剩余不足，先记未运行，不扩大预算。

所有固定分支保留，包括空问题、空候选、格式失败、核验反驳或无行动层面的新解释。完成这两个迁移例后停止自动追加，不以结果为由改图、改任务、改 gold 或再选其他案例。工程测试通过只能证明输入隔离和编码不改像素，不能证明解释合理或方法有效。
