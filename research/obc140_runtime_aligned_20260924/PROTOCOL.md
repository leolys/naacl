# 本轮公开输入协议

## 改变与不改变

唯一研究实施目的：纠正先前把 raw spec 当作实际公开任务的适配问题。原图、原数据、原评分与全部旧实验结果不变。新模型结果不能与旧记录混用。

公开输入来自原网页非 review 模式的 420 个已归档 GET 页面（140 × 入口／看板／表单）。仅投影真实可见任务目标、标题、图表说明、规则表、主选项标签及其顺序、伴随字段和提交文案。字段来源可逐项反查 HTML。隐藏 input、选项后台值、action_id、评分角色、gold、raw spec、另一图表条件不进入请求。

这是**静态图表及多页面公开任务文字**输入，不是自然网页浏览轨迹：每次模型看到一张未修改原图和固定公开 JSON，history 为空。无业务提交、无 browser action、无恢复率指标。公开规则和三个页面说明的加入会改变上下文总量，所以新旧差异不能单独归因为“去掉误导警告”。

“来自实际页面”指业务字段白名单投影，并不是转录所有页面装饰或元数据。原入口页中 environment35 / health19 共 54 条有公开显示的误导类型 chip；这些 benchmark 分类标签不进入新输入，与任务编号等门户元数据一并排除。没有修改原 HTML，也不能据此称原网页整体已无泄露。将来若运行完整网页截图 Agent，仍需独立处理这些可见标签。

## 提示与处理

- 原 proposal、observation_boundary_v4 OBC 生成与核验提示保持不变，沿用 public_task_citation_v1。
- O 直接观察、B 解释映射、C 结论的边界要求不变；模型违反边界也不人工改写英文。
- 每条依次 proposal、generation、verification，后一步依赖真实前一步成功。最多三条候选；单链和同选项候选如实保留。
- generation 正常结束时的既有纯闭合符处理保持不变，不补全内容或截断答案。所有无效、截断、未运行阶段保留区分。
- 不从旧结果挑任务：140 个公开输入均已改变，全部需要新生成。固定流程检查顺序 b001、pub003、env008；它们计入同一 140 条面板与同一预算，不重复采样。

## 原网页仍存在的限定

b003、b006、b008 原网页目标／规则明确使用 labeled rating share，公开规则还含 mislabeled_value。忠实对齐网页不等于完全无提示；这些文本保留并独立标记，不能自动改写为更难任务。其他未命中提示匹配规则的样本也不因此获得“完全无提示”的人工认证。

真实网页选项顺序可能已有位置或语义偏置。此轮不重新随机化、不改选项，只记录来源；任何后续去偏置应另立实验协议。

## 已授权资源

- 服务：已有 APIYI，模型请求名 gpt-5.6-terra；只能证实请求名和网关响应名，不能证明内部权重身份。
- 温度 0；输出上限 proposal 700、generation 2200、verification 2200；单并发。
- 用户新授权：最多 450 次真实请求尝试，20 美元估算账本上限；不是内网费用豁免，也不是供应商扣费保证。
- 每次失败、连接重试均计入。未知已发送结果不自动重发；结构或语义失败不做质量重采样。
- 中文由 Codex 与子代理原生翻译，另存 sidecar，0 次 APIYI 翻译。仅可复用英文字符串完全相同的中文映射，不复用旧模型答案。
- 不使用 GPU、不安装环境、不启动远程作业。原网页 HTML 仅作为本地离线来源，不调用提交接口。

## 记录与判定

保留 proposal、候选原文、规范化候选、核验、规则状态、失败响应、完整请求和成本。报告生成／核验结构通过率，不称其语义正确率。新旧解释可以描述性比较，不能作为随机化因果试验或已执行防御的成功率。

完成固定面板或达到预算后停止。不增加条件、换模型、扩展 benchmark、开发新机制。
