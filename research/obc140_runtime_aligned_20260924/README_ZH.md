# 140 条原网页任务对齐版：阅读入口

这是旧输入投影问题修复后的**独立新版本**。旧数据、图表、gold、旧模型结果和旧展示均保留。请不要把新展示同旧 `obc140_20260923` 目录中的解释混用。

## 怎么看

1. `OBC140_TERRA_ZH_REVIEW.html` 是最终单文件展示，双击即可离线打开，不需要 Python、项目或网络。只有明确生成此最终文件后才称最终展示；`PREVIEW_IN_PROGRESS.html` 是运行中快照。
2. 在左侧选择编号，依次查看任务原图、公开目标和选项、模型原提案、观察—解释规则—行动结论、竞争解释、核验记录及规则状态。中文是阅览层，可对照英文。
3. `RUNTIME_INPUTS_140_ZH.html` 专门展示修复后的公开任务及旧版差异，不含本轮模型解释。它的中文阅读导引不是发送给模型的文本；实际英文公开字段可展开查看。
4. 正式输出中的“无效”“失败”“未运行”各自保留。原始无效回答可用于人工检查，但不能算通过核验。单条解释也不会被补写成两条竞争解释。
5. 新版使用独立的本地审阅笔记标识，不自动继承旧展示的人工标记。手动导入旧笔记仍需逐条复核；导出笔记可跨电脑备份。

## 可核对的文件

- `REPORT.md` / `RESULTS.json`：实际状态、成本、边界和失败明细。
- `prepared/tasks/<编号>/public.json`：实际英文业务公开输入。
- `prepared/tasks/<编号>/provenance.json`、`prepared/sources/<编号>/`：不进入模型的来源记录与原网页快照。
- `prepared/input_comparison.json`：新旧公开字段逐项差异。
- `run/tasks/<编号>/record.json`：本轮英文规范记录；`translation=not_run` 表示中文由另一个本地阅览层生成，并非遗漏了翻译 API。
- `run/tasks/<编号>/<阶段>/round_001/request.json`：完整实际请求，包含发送的图像；同目录为实际响应、尝试回执与解析结果。尝试文件使用 `attempt_01.json` 等两位编号。
- `run/budget.json`、`run/summary.json`：累计尝试与估算用量。`run_state.json` 中的 `real_model_requests` 是初始化占位值，不能替代动态汇总和逐次请求证据。
- `run/runtime.json` / `run/runtime_source/`：实际运行代码版本与源码快照。
- `mode=LIVE_PROTOCOL_PREPARED` 是既有运行容器的名称，不是当前“未执行”状态。实际是否调用请看 `summary.json` 的状态、请求尝试数和逐次 HTTP 回执；mock 数据在另一目录，绝不计为真实调用。
- `prepared/` 中的 `model_status=not_run` 等字段是运行前冻结的准备信息，保留原样供追溯，不是当前实验进度。当前进度只读 `run/` 和最终报告。
- `translations/`：原生中文翻译与英文字符串对应关系；翻译不回流给被测模型。
- `reviews/`：独立上下文的同家族工程审查，结论为暂定，不冒充人工确认或跨模型研究验证。

## 人工阅览时重点看什么

- **观察**：是不是直接可见的颜色、位置、形状、刻度或文字？例如“颜色更浅”与“风险更高”不是同一层。
- **解释规则**：把颜色／数值映射到任务含义的规则是什么？是否明确写出条件，还是默认某个证据通道一定可信？
- **结论与行动**：是否确实满足公开任务目标、对应真实选项，而不只是重复图表标题？
- **竞争解释**：是否会导向不同选项或不同解释，而不仅是换种说法？如果没有，不能由阅览者替模型补出。
- **核验记录**：先区分未运行、结构无效与结构通过，再判断其引用和结论是否有可见依据。绿色阶段状态不是答案正确标记。

这些是人工阅读问题，不是本轮已经完成的人工标签，也没有发送给被测模型。

## 必须保留的解释范围

这是固定 140 张原图的静态解释生成和核验材料，不是 140 对双条件实验，也不是真实浏览器执行、最终提交或防御成功率。

公开字段采用原网页业务内容白名单，不是完整网页截图。原网页入口中的 54 条机制 chip 没有进入此次业务字段输入；图表本身不变。b003、b006、b008 原网页业务规则仍有标注数值等证据指导，原样保留，不能把整个新面板称为“完全无提示”。

没有给在线模型提供 gold、隐藏正确答案、原始数据表或另一 arm。模型、核验器和本地中文译者都可能有错误，结构通过不代表结论正确。
