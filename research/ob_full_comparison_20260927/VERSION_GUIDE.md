# 六配置比较说明

所有版本均逐字复用上一轮已存在的提示，不在本轮全量结果上调参。六版都重新运行140条，不复用原24条中表现好的结果。这里的名称解释版本差异，不预先宣称哪版更好。

| 配置 | 具体方案 | 正常请求数/任务 |
|---|---|---:|
| 普通直接选择 plain | 原图＋公开任务直接选择，不输入既有O/B或核验 | 1 |
| 原核验 v3 | 独立记录外观/印字→核验既有O事实和B适用条件→重新选择 | 3 |
| v4 可见参照核验 | 更明确记录数值参照与日期；核对B在图/任务中的实际适用、比较范围及基准 | 3 |
| v5 范围与条件实测 | 同系列参照约束查询点；逐个实测尺度、时间窗口、政策边界；优先使用能区分选项的范围 | 3 |
| v6 逐条件核验 | 先列B必要条件再逐项对照证据；常规监测、归档等也须正面依据，不是未知默认 | 3 |
| v7 范围决策 | READ和VERIFY逐字复用v4；DECIDE强调同系列位置和数值范围，不把缺少精确标注自动等同于不可判断 | 3 |

原v3本来已经区分外观和印字、检查B必要条件、不做O+B→C整链有效性判断。这些不是v4之后才出现的新原则。v3保留原数组ID/index schema，其他版本沿用上轮固定键和公开选项枚举；结果中的接口收益须单列，不算纯语义提示收益。

v4/v7前两阶段提示相同，但各自重新采样；相同seed也不保证输出相同。因此两版完整结果差别不能仅归因于最后一段提示。四个副本权重与参数相同，同任务六版在同一副本运行，版本顺序事前轮转。

这是固定既有275条O/B候选的核验与静态选择比较。136任务候选来自旧Terra批次，4任务使用此前补齐的Qwen候选；本轮不生成新反问链或持久化规则，也没有网页提交。原候选生成成本未包含在三次请求中，不能据此称完整方法仅三次请求。

分母始终140；空选项、接口失败和未完成不删除。另列原24开发子集与其余116，但140条历史上已被本研究使用，不是全新未见集。原标签相合不等于模型的读图、O/B核验理由都正确。
