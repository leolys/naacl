# 候选结论与核验分工：固定三例开发验证

## 本轮问题

生成器能否把采用某种读法时的具体 C 写完整，而不提前用证据缺口替代结论？反问负责补齐解释集合，不强迫发现冲突、不强迫新增链。错误或未证实的候选应保留给独立核验，不按 gold 删除或改写。

## 冻结范围

- b001、b002、pub013，均为已用于开发的原图例子，不是独立泛化测试。
- 每例：新初始生成 → 至多 3 个反问 → 至多 2 条补充链/2 个细化记录 → 独立核验 → 规则状态保存并重新读取。
- 新初始生成至多 3 链；不凑数量。已有集合覆盖时允许零问题、零新增。
- 若没有完整候选，问题只记录在链外；该例标为 `no_complete_candidate`，不伪造后续成功。
- 图、公共任务及选项来自已归档的运行时公开投影，不读取隐藏答案或另一图表条件。使用原 actor 的实际提议作为讨论参照，不读取原理由；参照不是正确答案，也不是已执行选择。
- 所有新阶段独立 API 请求，使用相同全图；后续阶段仅获得必要的当前候选记录。核验器不接收原提议、生成角色标签或问题结论。
- O 记录图面事实；解释假设放在 B/conditions；C 为具体任务结论。核验仍允许观察/适用性不确定，并独立判断条件推导。

## 成本和停止

本轮获授权的 gpt-5.6-terra APIYI，串行，temperature=0。正常最多 12 次请求，连失败与重试最多 16 次请求尝试、估算 3 美元。费用系数沿用历史测算，非当前账单保证。保留每次请求、原响应、模型路由字段、用量与预算预留。仅沿用原客户端的可重试连接超时/明确暂态 HTTP 策略，不对语义质量、解析或格式失败补跑；未知执行结果停止，不偷偷重采样。

零 GPU、零业务动作、零翻译 API。没有真实选择执行、提交或持续规则效果测试。页面审查使用本地浏览器，不计作被测 Agent 业务动作。

## 对照与可支持结论

历史结果只作为描述性参照。新初始生成、C 格式、后续提示与核验语义均有变化；不得把前后差异归因于某一句提示，也不是受控方法比较。结构通过只说明接口可读，不证明解释合理、观察准确、覆盖充分或纠错成功。初始即有竞争链时，反问没有新增链可以是合理结果。
