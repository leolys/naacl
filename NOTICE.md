# Private research collaboration copy

This is a curated private handoff, not an open-source/public-data release or a grant of rights to redistribute every contained item.

Original attribution and dataset notices are retained in `web_agent_benchmark/benchmark_v2_open/`. The project owner must review dataset and third-party figure permissions before any public release. No blanket MIT/Apache license has been added.

Sources were copied without changing the original working trees. Known credential-like literals in export copies were replaced with placeholders, with source and export SHA256 plus counts recorded in `handoff/SOURCE_PROVENANCE.json`.

The local Flask demonstration/session secret placeholders in this archive are not deployment secrets. Before using a web shell outside a trusted local experiment, configure an appropriate fresh secret and access controls; do not treat archived demo configuration as production-ready.

Excluded: optional Real-World40 and task-extension packages; the abandoned earlier evidence-revision/rollback project; peer-review/rebuttal/internal correspondence; unrelated candidate pools/projects; personal credentials/configurations; original Git history; model weights, environments and browser binaries; GPU guard scripts and other users' job material.
